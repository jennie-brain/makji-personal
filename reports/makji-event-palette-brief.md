# MAKJI 이벤트 페이지 팔레트

참고: https://m.makji.kr/ (2026-09-15 CSS 확인)

| 색상 | HEX | 근거·용도 |
|---|---|---|
| 브랜드 블루 | #4286C7 | 사이트 --main-color, 이벤트 주색상 |
| 포인트 레드 | #E01313 | 사이트 --point-color, 혜택·보상 배지 |
| 화이트 | #FFFFFF | 사이트 --background-color, 기본 배경 |
| 블랙 | #000000 | 사이트 버튼·본문 색상, CTA |
| 소프트 그레이 | #F8F8F8 | 사이트 --background-soft-color, 카드 배경 |
| 페일 블루 | #EAF3FB | 이벤트용 제안 확장색, 히어로·영역 구분 |

제안 면적 비율: 화이트 60 / 페일 블루 20 / 블루 10 / 블랙 8 / 레드 2.
면적 비율과 페일 블루는 공식 브랜드 가이드가 아니라 이벤트 디자인 제안이다.

생성 방식: 내장 이미지 생성 도구.

생성 프롬프트 요약: 확인된 사이트 색상을 사용한 가로형 MAKJI EVENT PALETTE 보드. 원본 색상과 제안 확장색 구분, HEX·역할 표시, 이벤트 히어로·쿠폰 카드·참여 버튼 적용 예시, 색상 면적 비율. 화이트·블루 중심에 레드를 소량 사용하며 장식은 최소화한다.

이미지는 시각적 제안용이며 실제 구현 색상은 위 HEX 값을 사용한다.
