# MAKJI STOCK 배포본 UI/UX 검토

- 검토 대상: [makji-stock.vercel.app/market](https://makji-stock.vercel.app/market)
- 검토일: 2026-09-23
- 범위: 모바일 MARKET 화면의 첫 진입, 상품 탐색, 가격 이해, 가격 잠금, 보상 선택, 자사몰 이동
- 목적: “지금 구매”를 가장 쉬운 선택으로 만들면서 가격 잠금과 예측이 재방문 장치로 작동하게 한다.
- 상태: 구현 전 개선 권고안

---

## 한 줄 결론

현재 화면은 브랜드 톤과 시세 탐색 경험은 잘 잡혀 있지만, **가격을 이해하고 즉시 구매하는 흐름보다 지수·정렬·보상 게임이 먼저 읽힌다.** 특히 상품 행의 화살표와 퍼센트가 서로 다른 기준을 섞어 보여 주는 문제는 가격 신뢰를 해칠 수 있으므로 우선 수정한다.

## 잘 작동하는 부분

- 아이보리·블루 중심의 차분한 톤과 빵 사진이 금융형 인터페이스의 긴장을 낮춘다.
- 오전장·오후장·정가 시간과 다음 가격 시각을 상단에서 지속적으로 알린다.
- 6종을 한 화면에서 비교하고 할인 많은 순으로 정렬할 수 있다.
- 가격 잠금, 가격 추이, 상세 계산, MY 기록을 바텀시트로 분리해 한 화면에 과도한 정보를 쌓지 않았다.
- 잠금은 오전장 하루 한 번이라는 제약을 카드와 상품 행에 함께 드러낸다.

---

## 출시 전 수정할 항목

### 1. 가격 등락과 할인율을 분리해서 표시한다

현재 상품 행은 화살표를 직전 확정가 대비 방향으로 표시하면서, 같은 줄의 퍼센트는 정가 대비 할인율로 표시한다. 예를 들어 `▲ 28.9%`는 “28.9% 올랐다”로 읽히지만 실제로는 “직전가 대비 상승했어도 정가에서는 28.9% 할인”일 수 있다.

이 요소는 다음처럼 분리한다.

```text
2,700원
28.9% 할인
어제보다 120원 내려갔어요
```

- `28.9% 할인`은 할인 배지 또는 고정된 할인 라벨로 보여 준다.
- `어제보다` 정보에는 실제 변동 금액과 실제 변동률만 함께 쓴다.
- 상승·하락 색과 화살표는 실제 전일 대비 값에만 쓴다.

### 2. 즉시 구매 CTA를 첫 화면에 올린다

현재 첫 화면은 막지지수, 잠금 안내, 산식 설명, 정렬, 상품 목록 순으로 읽힌다. 안정형 보상과 예측 카드는 상품 여섯 개를 지나야 도달한다.

사업 목표가 즉시 구매 전환이라면, 첫 화면에는 오늘의 혜택과 구매 행동이 있어야 한다.

```text
오늘 빵 6종 평균 24.9% 할인 중
오늘 가장 큰 혜택: 휘낭시에 2,700원

[10~14% 추가 할인받고 구매하기]

가격이 오를까 걱정된다면
[오늘 가격 잠그기]
```

가격 잠금과 예측은 구매를 미루는 사용자에게 제공하는 보조 경로로 둔다.

### 3. 눌릴 것처럼 보이는 잠금 안내 카드를 실제 행동으로 연결한다

`오전가 잠금 · 하루 1개` 카드는 카드 스타일이라 누르면 이동할 것처럼 보이지만, 잠금 전에는 단순 안내 요소다. 사용자가 눌렀을 때 반응이 없으면 어포던스가 깨진다.

다음 중 하나를 적용한다.

- 카드 전체를 눌러 잠글 상품 목록으로 이동한다.
- 카드 안에 `잠글 빵 고르기 →` 버튼을 둔다.
- 단순 안내로 유지할 경우 카드의 강조도를 낮춘다.

권고안은 카드 전체를 상품 선택으로 연결하고, 문구를 다음처럼 바꾸는 것이다.

> 오후에 가격이 올라도 지금 가격으로 살 수 있어요.  
> **잠글 빵 고르기 →**

### 4. 안정형 보상과 구매를 한 흐름으로 연결한다

현재 안정형의 `지금 바로 받기`는 할인코드만 발급하고 MY로 돌아간다. 사용자는 쿠폰을 받은 뒤 다시 상품을 찾아 자사몰로 이동해야 한다. “지금 바로”라는 문구가 암시하는 행동과 실제 흐름이 다르다.

안정형의 주 CTA는 다음처럼 설계한다.

```text
10~14% 할인받고 구매하기
→ 1회용 코드 발급
→ 코드 복사 또는 자동 적용 안내
→ 해당 상품 자사몰로 이동
```

`안정형 투자`보다 `지금 할인받기`, `공격형 투자`보다 `내일 더 큰 할인 도전`처럼 행동을 중심으로 이름을 붙인다.

### 5. 잠금 버튼의 라벨을 상태가 아니라 행동으로 쓴다

현재 `오전장`, `06시`, `휴장` 라벨만으로는 사용자가 무엇을 할 수 있는지 알기 어렵다. 버튼과 근처 보조 문구를 다음처럼 바꾼다.

| 상태 | 권장 라벨 |
|---|---|
| 잠금 가능 | 가격 잠그기 |
| 다른 상품에 이미 사용 | 오늘 잠금 사용 |
| 오후장 이후 | 오늘 잠금 종료 |
| 주말·휴장 | 평일에 이용 가능 |
| 잠금 완료 | 잠금 확인 |

비활성화한 버튼에는 비활성 이유를 버튼 가까이에 보여 준다.

### 6. 배포 화면의 할인 정책 문구를 최신 정책과 일치시킨다

현재 배포 화면은 시장 할인 최대 38%, 안정형 10~15%, 공격형 5~20%를 안내한다. 기획 문서의 최신 권고안은 시장 할인 최대 20%, 안정형 10~14%, 공격형 15~18%, 최종 총혜택 최대 38%다.

화면 문구, 할인코드 발급 로직, 실제 결제 금액이 서로 다르면 가격 신뢰가 크게 무너진다. 정책 변경 시 세 영역을 같은 배포 단위로 변경한다.

## 다음 우선순위 개선

### 막지지수보다 실제 혜택을 먼저 보여 준다

`75.14pt`는 시세 경험에는 적합하지만 일반 구매자에게 즉시 의미가 약하다. 다음처럼 구매 의미를 먼저 보여 주고 지수는 보조 정보로 낮춘다.

```text
오늘 6종 평균 24.9% 할인 중
MAKJI INDEX 75.14
```

### 상품 행에 상세 진입 신호를 준다

상품 사진과 이름, 가격은 상세 시트를 열 수 있으나 버튼처럼 보이지 않는다. 행 전체의 눌림 상태, `›` 아이콘 또는 `상세보기` 보조 문구로 다음 행동을 명확히 한다. 잠금 버튼은 별도 보조 행동으로 유지한다.

### `급등주`를 검색 신호에 맞는 말로 바꾼다

현재 `급등주`는 검색 관심이 오른 상품을 뜻하지만, 금융 문맥에서는 가격이 오른 종목으로 오해될 수 있다. `검색 급상승`, `오늘 관심 급상승`, `인기 상승`을 권장한다.

### 동일 목적지의 구매 링크를 하나로 합친다

상세 시트의 `막지 자사몰에서 구매`와 `이 상품 보러 가기`는 같은 목적지다. 주 CTA 하나만 남긴다.

> **2,700원에 지금 구매하기**

## 접근성·모바일 완성도

- 9~11px 설명 문구를 핵심 정보에서는 최소 12~13px로 높인다.
- 연한 회색 보조 텍스트의 명도 대비를 높인다.
- `title` 속성에만 있는 가격 설명은 모바일에서 보기 어려우므로 화면에 직접 표시한다.
- 바텀시트는 키보드 초점을 시트 안에 가두고, 닫으면 기존 버튼으로 초점을 돌린다.
- 자동 움직이는 시세 테이프에는 `prefers-reduced-motion` 대응을 넣는다.
- 자사몰을 새 탭으로 열면 `새 창으로 이동`임을 버튼에서 알린다.
