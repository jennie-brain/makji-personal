## 3. 기획 배경(WHY) 슬라이드 신설 — 5월 실데이터 기반으로 교체

**배경**: 9/14본 슬라이드4(기획배경)는 외부 학술 연구(시간제한 프로모션 실험) 인용이 주 근거였다. 사용자가 5월 자사몰 베타 운영 데이터(CSV 2건)를 바탕으로 재작성을 제안했고, ChatGPT의 피드백을 받아왔다. 이를 검증·종합한 결과가 목차개편안.md 2절이다.

**GPT 피드백 검증 결과**: 로그인90·가입40·결제상품145개·금액340.8만원(시간별파일), 생성주문147·결제>0인 108건·결제=0인 39건·미결제비중26.5%(주문파일), 오전/저녁 시간대 비중까지 — CSV 원본을 직접 열어 전부 재계산했고 모두 일치했다.

**GPT가 놓친 것(추가 검증)**: "결제금액=0" 39건 중 37건의 결제수단이 '선불금'이었다. 같은 결제수단인데 결제금액이 정상 표시된 주문도 있어, 이 39건이 진짜 결제 이탈인지 선불금 처리 시 필드가 0으로 찍히는 표시 방식인지 데이터만으로는 확정할 수 없다. GPT는 이를 "결제 이탈"로 단정했으나, 목차개편안에는 "결제 완료 여부 확인 필요"로 톤을 낮춰 반영했다 — 기업대표 앞에서 자사 결제 데이터를 잘못 해석해 제시하는 리스크를 피하기 위함.

**"유입 대비 낮은 전환율" 표현을 쓰지 않은 이유**: 로그인 횟수는 방문자·세션 수가 아니고, 시간별분석 파일과 주문내역 파일 사이에 사용자를 연결할 키가 없어 실제 방문→구매 퍼널 전환율은 계산 불가능하다(GPT 피드백과 동일 결론). "관심·가입·주문·결제가 서로 다른 시간대에 흩어져 있다"는, 데이터로 뒷받침되는 표현만 사용한다.

**B2B→B2C 확장 서사**: 처음에는 이 세션 어디에도 근거가 없어 보류를 제안했으나, 2026-09-23 사용자가 직접 확인 — 막지는 실제로 B2B에서 B2C(자사몰)로 사업을 확장하는 과정이 맞다. 확인 후 슬라이드 제목·상단 메시지에 반영했다.

**외부 연구를 각주로 내린 이유**: 내부 실측 데이터가 있는 상태에서 외부 학술 연구를 메인 근거로 쓸 이유가 없다는 GPT 판단에 동의 — 2020년 현장실험(n=182)·2023년 조사(n=501)는 "시간제한·가격변동이 구매행동에 영향을 준다"는 일반론을 보조하는 각주로만 남긴다.

## 4. 성공 조건 3개를 차별화 전략 3개와 1:1로 재정의

**배경**: 사용자가 "성공조건 3개와 차별화전략 3개를 한 슬라이드에 넣으면 어떠냐"고 제안했다. 확인해보니 舊 성공조건(체감·끊김없는구매전환·질리지않는재미)은 차별화전략(①가격의콘텐츠화 ②투명한체감 ③위험성향별리워드)과 깔끔한 1:1이 아니었다 — 체감↔②는 사실상 중복, 질리지않는재미↔①은 대응됐지만, 끊김없는구매전환은 대응 전략이 없고(원래 "전제조건이지 차별점 아님"으로 정의했던 항목) 전략③은 대응 조건이 없었다.

**해결**: 사용자가 조건2·3의 실제 의미를 다시 짚었다 — 조건2는 "간편하게 주도적으로 선택하는 혜택"(잠금·예측), 조건3은 "주식시장 모티브·가격 변동 그 자체"였다. 이렇게 재정의하면 조건2↔전략③, 조건3↔전략①로 자연스럽게 맞아떨어진다.

**"끊김없는 구매전환"을 성공조건에서 뺀 이유**: 사용자가 "이건 내가(우리 실행으로) 해결할 수 있는 문제가 아니다"라고 짚었다 — STOCK과 자사몰의 결제 시스템 분리는 RFP 요구사항 자체이므로, 두 사이트를 하나로 합쳐 마찰을 원천 제거하는 건 제품팀 실행 범위 밖이다(원클릭·자동인식으로 마찰을 줄이는 것만 가능). "실행하면 갖출 수 있는 조건"이라는 성공조건의 정의와 맞지 않아, "안고 가야 할 구조적 제약"인 13번 핵심 리스크 슬라이드로 옮겼다. 시장분석06 AOS·DOS 전체 1위(C3)라는 중요도는 그대로 유지 — 사라진 게 아니라 더 정확한 자리로 옮겨졌다.

## 5. 슬라이드 5·6 병합 및 신설 — 시장 현황과 문제 / 문제정의와 솔루션

**배경**: 舊 5번(시장문제)·6번(경쟁환경)이 둘 다 "왜 이 판이 어려운가"를 다른 각도(거시 시장 vs 경쟁사)에서 말하는 것뿐이라 사실상 한 묶음이었고, 정작 "고객이 실제로 어디서 이탈하는가"는 어느 슬라이드에도 없었다. 사용자가 두 슬라이드를 합치고, 그 다음에 "문제정의와 솔루션"을 압축하는 브릿지 슬라이드를 두자고 제안해 채택했다.

**병합 방식**: 5번을 3단 패널(시장문제/경쟁구도/고객이탈지점)로 재구성했다. 고객 이탈지점은 이미 만들어둔 페르소나 Pain(N1·정은숙의 사행성 거부, C2·김소민의 신뢰부족)을 그대로 가져왔다 — 시장분석05·06에서 이미 나온 근거를 덱에서는 안 쓰고 있었던 것을 바로잡은 것이다. STOCK→자사몰 전환마찰(C3)은 이미 13번 리스크로 옮겼으므로 중복 배치하지 않았다.

**슬라이드 수 변화 없음**: 5·6번이 합쳐져 1개 슬라이드가 되고, 신설된 "문제정의와 솔루션"이 그 자리를 메워 전체 슬라이드 수(17개)는 그대로다. 7번 이후 번호는 전혀 밀리지 않는다.
