## 2. 슬라이드 9 상세 — 소비자 화면 흐름 (3개 흐름)

프로토타입 스크린샷이 아니라, 기능별로 사용자가 실제로 거치는 **논리적 흐름**을 3개로 나눠 보여준다. 세 흐름 모두 마지막은 "자사몰 이동·구매"로 끝나되, 각 흐름이 겨냥하는 사용자 심리와 관문이 다르다.

### 흐름 ① 기본 구매 전환 — 유입→온보딩→자사몰

가장 단순한 경로. 잠금도 예측도 쓰지 않고 그 자리에서 사는 사용자다.

```
SNS·광고 유입
  → 온보딩 5장(빵값이 왜 움직이나 ~ 어디서 사나)
  → Bread Market에서 오늘 가격 확인
  → 마음에 드는 상품 선택
  → "막지에서 구매하기" → 자사몰 이동
  → 회원가입·로그인 → 구매 완료
```

### 흐름 ② 가격 잠금 — 아침 방문, 오후 재방문

오전에 들어왔지만 "오후에 가격이 오르면 어떡하지"라는 망설임이 있는 사용자를 위한 흐름. 잠금이 그 망설임을 없애 방문을 두 번으로 늘린다.

```
오전장(06:00~15:59) 방문
  → 마음에 드는 빵의 오전가 확인, 오후 가격 변동이 걱정돼 구매를 망설임
  → "가격 잠금" 선택(하루 1회) → 오전가가 보장가로 고정됨
  → (이탈 — 오늘은 결제까지 가지 않음)
  → 16:00 오후장 재방문
  → 오후가 확인:
      오후가가 올랐으면 → 보장가와의 차액을 쿠폰으로 보전, 보장가로 구매
      오후가가 내렸으면 → 잠금 안 쓰고 더 싼 오후가로 구매
  → 자사몰 이동 → 구매 완료
```

### 흐름 ③ 오늘의 보상 고르기 — 안정형 즉시구매 vs 공격형 예측·재방문

같은 화면에서 두 갈래로 갈린다. "지금 바로 사고 싶은 사람"과 "위험을 감수하고 더 큰 혜택을 노리는 사람"을 분리해서, 즉시 전환과 재방문 유도를 동시에 만든다.

```
"오늘의 보상 고르기" 화면 진입 → 안정형 / 공격형 선택

[안정형 — 지금 바로 구매할 사람]
  → 선택 즉시 정해진 범위 내 랜덤 확정 쿠폰 지급
  → 자사몰 이동 → 바로 구매 완료

[공격형 — 하이리스크·하이리턴, 투자형 사용자]
  → 내일 가격이 오를지 내릴지 예측 참여
  → 안정형보다 훨씬 넓은 범위의 랜덤 할인율을 걸고 대기(익일 06:00 판정)
  → (이탈 — 오늘은 쿠폰 없음, 결과가 궁금해서 다음 날 재방문)
  → 익일 06:00 재방문 → 예측 결과 확인
  → 적중 시 폭넓은 범위의 쿠폰 수령 → 자사몰 이동 → 구매 완료
```

**세 흐름의 공통점과 차이**: 셋 다 마지막은 자사몰 구매로 수렴하지만, ①은 방문 1회로 끝나고 ②·③은 의도적으로 방문을 2회로 쪼갠다 — ②는 "망설임 해소"로, ③은 "결과가 궁금해서"로 재방문 동기를 만든다는 점이 다르다. 발표덱에서는 이 차이를 하나의 흐름도에 욱여넣지 말고 3개 패널(또는 3개 슬라이드)로 나눠 각각 완결된 스토리로 보여준다.
