검색지수 × 0.15

0~15% 할인. 많이 찾는 빵에 할인을 더해 첫 구매를 끌어옵니다.

원가 신호

환율 (원/달러)

내리면 하락률×14 전부 환원(최대 +28%), 오르면 ×7 절반만 반영.

안전장치

0% ~ 38% 고정

정가를 절대 넘지 않고, 잠금·예측 쿠폰을 합쳐도 38% 이내.

= clamp( 검색 할인 + 환율 조정 , 0 , 38 )

판매가 = 정가 × (1 − 총 할인율), 10원 단위 반올림
