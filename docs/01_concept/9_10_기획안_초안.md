## 1. 서비스 소개

> MAKJI STOCK은 **검색트렌드**와 **환율**을 반영해 매일 달라지는 빵값을 보여주는 서비스입니다.
> 

사용자는 **MAKJI STOCK에서 오늘 빵값을 확인하고, 구매할 상품을 선택하면 막지 자사몰로 이동**합니다. 

두 사이트는 별도로 운영하며, 실제 주문과 결제는 막지 자사몰에서 진행합니다.

| 항목 | 내용 |
| --- | --- |
| 서비스명 | MAKJI STOCK |
| 타깃 사용자 | 매일 달라지는 빵 시세와 혜택을 확인하며, 단순 구매를 넘어 새로운 구매 경험을 즐기는 온라인 베이커리 소비자 |
| 핵심 가치 | 매일 새로운 가격을 확인하고 원하는 빵의 구매 시점을 판단하는 경험 |
| 핵심 메시지 초안 | 검색할수록 내려가는 빵값 |

### 방문 동기

매일 달라지는 빵값을 확인하고, 원하는 빵을 저렴하게 살 기회를 찾기 위해 방문합니다.

**핵심 이용 경험:** 오늘 빵값 확인 → 상품 비교 → 막지 자사몰에서 구매

**추가 참여 경험:** 내일 가격 예측 → 다음 날 결과 확인 → 성공 시 할인 쿠폰

핵심 메시지는 검색 관심도를 할인 혜택으로 연결한다는 뜻입니다. 개인의 검색 한 번이 즉시 할인으로 바뀌는 구조는 아니며, 최종 가격에는 환율도 반영됩니다.

## 2. 기획 배경

> 매일 달라지는 빵값으로 MAKJI STOCK에 다시 방문할 이유를 만들고, 관심 상품의 구매를 막지 자사몰로 연결합니다.
> 

### 2-1. 기업의 요구

- 기업 RFP는 외부 시장 데이터를 식품 구매 경험에 연결해 **상품 관심·재방문·구매 전환**을 유도하는 기능을 요구합니다.
- 메타 광고용 이벤트 페이지와 SNS 홍보 소재를 통해 신규 고객을 유입하고, 자사몰 구매로 연결하는 프로모션도 요구합니다.

### 2-2. 기획 방향

구매할 상품이 정해져 있지 않아도, **오늘 가격이 궁금해서 상품을 둘러보게 하는 것**이 출발점입니다.

검색트렌드와 환율로 매일 가격을 계산하고, 상품별 가격 추이를 제공합니다. 사용자는 가격을 비교한 뒤 구매를 결정하거나 다음 날 다시 확인할 수 있습니다. 

### 2-3. 프로젝트 목표

| 대상 | 목표 |
| --- | --- |
| 사용자 | 오늘 가격과 이전 가격을 비교하고 구매할 상품을 선택 |
| MAKJI STOCK | 가격 확인을 위한 반복 방문과 상품 탐색 유도 |
| 막지 자사몰 | 관심 상품 페이지로의 유입과 실제 구매 기회 확대 |

## 4. 핵심 콘텐츠

> 오늘의 빵시장이 중심 콘텐츠이며, 내일 가격 예측은 재방문을 돕는 추가 콘텐츠입니다.
> 

### 4-1. 오늘의 빵시장

| 항목 | 내용 |
| --- | --- |
| 대상 상품 | MAKJI 상품 10종 |
| 오늘 시세 | 검색트렌드와 환율을 반영해 계산한 상품별 가격 |
| 가격 변화 | 비교 기준과 함께 표시하는 가격 차이·비율 |
| 가격 추이 | 날짜별 가격을 확인하는 그래프 |

가격 변화의 화면 표시 기준은 기본가격 대비입니다.

### 4-2. 내일 가격 예측

오늘 선정된 빵의 내일 가격이 오를지 내릴지 선택합니다. 

다음 날 가격이 확정되면 예측 결과를 안내하고, 성공한 참여자에게 할인 쿠폰을 제공하는 안입니다.

| 항목 | 현재 기획 |
| --- | --- |
| 예측 상품 | 10종 중 무작위로 선정한 상품 |
| 선택지 | 오른다 / 내린다 |
| 비교 기준 | 해당 상품의 오늘 가격과 내일 가격 |
| 결과 | 예측 성공 또는 실패 안내 |
| 보상 | 성공 시 할인 쿠폰 제공 제안 |

### 4-3. 자사몰 유입 프로모션

메타 광고와 SNS 홍보 소재를 통해 신규 고객을 MAKJI STOCK으로 유입하고, 이벤트 참여를 자사몰 구매로 연결합니다.

- **데일리 뉴스레터:** 시장 정보와 오늘의 빵 콘텐츠 제공
- **빵 자르기 게임:** 가볍게 참여할 수 있는 이벤트 콘텐츠
- **오늘의 빵 운세:** 매일 확인할 수 있는 데일리 콘텐츠

**유입 흐름:** SNS·메타 광고 → 이벤트 페이지 → Bread Market·상품 상세 → 막지 자사몰 구매

## 6. 외부데이터와 가격 정책

> 검색 관심도와 환율 변화로 가격을 계산하고, 상품 가격대에 따라 변동 범위를 제한합니다.
> 

### 6-1. 사용하는 데이터

| 구분 | 데이터 | 활용 목적 | 확보 계획 |
| --- | --- | --- | --- |
| 외부데이터 | NAVER 검색트렌드 | 상품별 관심도를 가격에 반영 | NAVER API HUB |
| 외부데이터 | USD/KRW 환율 | 금융시장 변화를 상품 가격에 공통 반영 | 한국수출입은행 관련 API |
| 기업 자료 | 상품명·기본가격·원재료·이미지 | 실제 상품과 시세 연결 | 기업 제공·협의 |
| 서비스 기록 | 방문·상품 조회·예측·쿠폰 기록 | 운영과 효과 검증 | 우리 서버에 저장하는 구조 설계 |

### 6-2. 가격 결정 원칙

1. 검색트렌드 점수가 높을수록 가격을 낮추는 방향으로 반영합니다.
2. 환율 변동을 더하므로 최종 가격은 상승하거나 하락할 수 있습니다.
3. 전날 가격에 누적하지 않고 매일 기본가격에서 다시 계산합니다.
4. 가격대별 한도를 적용하고 10원 단위로 반올림합니다.

> 검색트렌드 반영 + 환율 반영 → 가격대별 한도 적용 → 기본가격에서 계산 → 10원 단위 반올림
> 

**현재 기준점·반영 비율·가격대별 한도는 임시 설정입니다.** 가격 변화 정도와 상품별 원가·마진을 확인한 뒤 조정합니다. 

### 6-3. 현재 검토 중인 수치

| 요소 | 임시 설정 |
| --- | --- |
| 검색트렌드 | 점수 0.5를 기준으로 최대 ±5% 반영. 점수가 높으면 인하, 낮으면 인상 |
| 환율 | 전일 대비 변동률을 3배로 반영하되 최대 ±3%로 제한 |
| 합산 범위 | 최대 ±8% |
| 가격대별 실제 계산 범위 | 1만원 미만 ±8% / 1만~2만원 미만 ±7% / 2만원 이상 ±5% |

### 6-4. 표시 기준과 데이터 갱신

- **기본가격 대비 조정률:** 가격 계산에 사용하는 비율.
- **전일 대비 등락률:** 오늘 가격이 전날 가격에서 얼마나 달라졌는지 보여주는 비율.
- 조회 주기, 적용 데이터의 기준일, 가격 갱신 시각은 운영 정책으로 정합니다.
- 검색 점수의 조회 기간·검색어·0~1 환산 방식을 확정해야 실제 데이터에 공식을 적용할 수 있습니다.
- 휴일·미공시·조회 실패 시 가격 유지 또는 갱신 보류 여부를 정합니다.

### 7-3. 비로그인 참여와 쿠폰 전달 검토안

우리 사이트에는 로그인 기능을 두지 않는 방향입니다. 참여 기록을 찾는 방식은 아래 두 안을 비교해 결정합니다.

| 안 | 기록 확인 방법 | 고려할 점 |
| --- | --- | --- |
| 브라우저 익명번호 | 브라우저에 저장한 번호로 서버 기록 조회 | 입력 없이 이용 가능. 다른 브라우저나 사이트 데이터 삭제 후에는 기록 확인이 어려움 |
| 참여번호·확인 비밀번호 | 사용자가 입력한 정보로 서버 기록 조회 | 다른 기기에서 확인 가능. 분실·중복 입력·인증 처리 필요 |

쿠폰은 **카페24에서 미리 발급한 쿠폰 번호를 성공한 참여 기록에 배정하는 안**을 검토합니다. 사용자는 우리 사이트에서 번호를 확인한 뒤 막지 자사몰에서 로그인·등록해 사용합니다. 세부 방식은 기업과 확인 후 확정합니다.

### 7-4. 콘텐츠·오류 관리

- RFP에 따라 상품 이미지·설명은 기업 제공 자료와 사전 협의를 거쳐 적용합니다.
- 상품 콘텐츠를 AI가 임의 생성·선정하거나 자동 업로드하는 방식은 사용하지 않습니다.
- 데이터 수집, 가격 반영, 결과 판정, 쿠폰 처리의 성공·실패 기록을 남기는 구조로 설계합니다.
- 운영자는 실패 내역과 반영 상태를 확인합니다. 복구·재처리 기준은 운영 정책으로 정합니다.

## 부록 B. 상세 가격 계산

아래는 팀의 임시 계산안입니다. 현재 배포 사이트나 시뮬레이터에 이 식이 반영됐다는 뜻은 아닙니다.

### B-1. 계산식

- 검색트렌드 조정률 = ((0.5 − 검색트렌드 점수) ÷ 0.5) × 5%
- 환율 조정률 = 환율 전일 대비 변동률 × 3, 최대 ±3%로 제한
- 합산 조정률 = 검색트렌드 조정률 + 환율 조정률
- 최종 조정률 = 합산 결과에 가격대별 한도를 적용한 값
- 오늘 가격 = 기본가격 × (1 + 최종 조정률), 10원 단위 반올림
- 전일 대비 등락률 = (오늘 가격 ÷ 전날 가격 − 1) × 100%

예: 기본가격 3,800원, 검색 점수 0.75, 환율 전일비 +0.5%일 때 검색 −2.5%와 환율 +1.5%를 더해 −1%를 적용합니다. 3,800원 × 0.99 = 3,762원이므로 최종 가격은 **3,760원**입니다.
