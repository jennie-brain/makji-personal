## 1. ⚠️ 일반명사 마스킹(Masking) 왜곡 분석 및 정제 배경

### 1) 기술적 사실 (1회 검색 시 2중 집계 여부)
- 네이버 데이터랩 API의 `keywords` 배열은 **검색 쿼리 로그 단위의 `OR(합집합)` 조건**으로 집계됩니다.
- 따라서 사용자가 "무설탕카스테라"를 검색했을 때 해당 그룹 내에서 **1번의 검색이 2번으로 중복 카운트(Double Counting)되는 기술적 에러는 발생하지 않습니다.**

### 2) 데이터 분석 및 기획적 진짜 문제점: '볼륨 흡수 왜곡(Masking)'
- 일반 명사 **"카스테라"**는 전국 일간 검색량이 수만 건에 달합니다.
- 반면 타깃 제품인 **"무설탕카스테라"**, **"제로카스테라"**는 일간 검색량이 수십~수백 건에 불과합니다.
- 이들을 `["카스테라", "무설탕카스테라", "제로카스테라"]`로 함께 묶으면, **수치의 99%는 그냥 일반 대중의 카스테라 검색량이 차지**하게 됩니다.
- 결과적으로 MAKJI가 의도한 **"다이어트·저당 웰니스 빵에 대한 고객의 특별한 관심도 변화"가 거대한 일반명사 볼륨에 완전히 묻혀(Masking) 변별력이 상실**됩니다.

### 3) v2.0 정제 조치
- 일반 단독 명사(`카스테라`, `초코케이크`, `머핀`, `스콘`, `샌드위치` 등)를 과감히 제거!
- **순수 웰니스 속성(무설탕/제로/글루텐프리/비건) + 구체적 구매의도 롱테일 키워드**만으로 10종 그룹을 100% 리팩토링했습니다.

## 2. 키워드 설정 4대 핵심 원칙

1. **마스킹 노이즈 제거 (Noise Filtering):** 거대 볼륨의 일반 명사를 제외하고, 타깃 고객의 진성 검색어만 남김
2. **유의어 번들링 (Synonym Bundling):** 0 지수(Zero Index) 및 소수 검색에 따른 급등락을 막기 위해 4~6개의 유의어 묶음 질의
3. **개별 14일 이동평균 모멘텀 ($M$):** 타 제품과의 절대 검색량 비교가 아닌, 해당 빵 자신의 과거 14일 평균 검색량($\mu_{14}$) 대비 당일 급증/급감 비율 측정
4. **5개 그룹 분할 호출 (Batch Calling):** 네이버 API 1회 최대 5개 그룹 제약에 따라 1~5번(식사빵/구움과자)과 6~10번(케이크/식빵/생지) 2회 분할 전송

## 5. 검색 지수의 빵 시세 환산 공식 및 예외 방어

### 1) 당일 검색 모멘텀($M$) 산출
$$\mu_{14} = \frac{1}{14} \sum_{i=1}^{14} T_i \quad \text{(14일 이동평균 지수)}$$
$$M = \frac{T_{\text{today}} - \mu_{14}}{\max(\mu_{14}, 1.0)}$$
> **Division by Zero 방어:** 분모에 `max(μ_14, 1.0)`을 두어 과거 검색량이 0에 수렴할 때 발생하는 `NaN` 오류를 원천 방지합니다.

### 2) 민감도 계수($\alpha$) 적용 및 트렌드 한도 클램핑
$$\Delta\text{Trend} = \max\left(-5.0\%, \min\left(+5.0\%, M \times \alpha\right)\right) \quad (\alpha = 0.0833)$$
- 검색량이 `+60%` 이상 폭증하면 트렌드 상한인 **`+5.0%` (인기 대장주 프리미엄)** 도달
- 검색량이 `-60%` 이상 감소하면 트렌드 하한인 **`-5.0%` (깜짝 알뜰 줍줍 특가)** 도달

### 3) 거시 환율($\Delta\text{FX}$) 결합 및 3단계 차등 캡 적용
$$\text{RawRate} = \Delta\text{Trend} + \Delta\text{FX}$$
$$\text{FinalRate} = \max(-\text{TierCap}, \min(+\text{TierCap}, \text{RawRate}))$$

* **Tier 1 (1만원 미만 5종):** $\text{Cap} = \pm10\%$ (체감 재미 극대화)
* **Tier 2 (1만~2만원 3종):** $\text{Cap} = \pm7\%$ (부담 없는 일상 디저트)
* **Tier 3 (2만원 이상 2종):** $\text{Cap} = \pm5\%$ (마진 리스크 철통 방어)
