# MAKJI STOCK 빵마켓 MVP PRD

문서 버전: 1.0<br>
기준일: 2026-09-15<br>
상태: 프로토타입 검증용

## 1. 제품 정의

MAKJI STOCK 빵마켓은 환율과 검색트렌드를 반영한 막지 제품의 오늘 가격을 매일 오전 9시에 공개하는 모바일 우선 서비스다. 사용자는 주식 종목을 살펴보듯 다섯 가지 빵의 가격과 흐름을 비교하고, 선택 상품의 가격 변동과 할인 근거를 확인한 뒤 막지 공식 자사몰에서 구매를 이어간다.

핵심 문장: **매일 달라지는 빵값이, 매일 다시 찾는 막지를 만듭니다.**

## 2. 해결하려는 문제

- 고정된 상품 진열과 가격만으로는 다음 날 다시 방문할 이유가 약하다.
- 광고 유입 사용자가 상품을 탐색할 만한 콘텐츠가 부족하다.
- 할인율만 제시하면 가격이 왜 달라졌는지 이해하기 어렵다.
- 가격 확인과 실제 구매가 서로 다른 서비스에서 진행되므로 이동 맥락을 명확히 알려야 한다.

## 3. 목표와 비목표

### 목표

1. 방문 즉시 오늘 가격과 기준가 대비 할인율을 이해하게 한다.
2. 다섯 상품의 가격 흐름을 비교하고 상품 상세로 이동하게 한다.
3. 환율 할인과 검색트렌드 할인을 소비자 언어로 설명한다.
4. 선택 상품과 최종가격을 유지한 채 `makji.kr` 구매 페이지로 연결한다.
5. 가격 확인을 매일 반복할 수 있는 콘텐츠로 만든다.

### 비목표

- MAKJI STOCK 안에서 주문·결제를 처리하지 않는다.
- 구매와 무관한 종합 지표, 개인화 보관, 회원 기능을 MVP에 포함하지 않는다.
- 운영 대시보드나 가격 산식을 소비자 화면에 노출하지 않는다.
- 구매 전환이나 최적 할인율이 이미 검증되었다고 주장하지 않는다.

## 4. 대상 사용자와 핵심 상황

주 사용자는 건강한 빵과 할인 혜택에 관심이 있고, 인스타그램·카카오톡 등 모바일 채널에서 막지를 처음 접하거나 재방문하는 소비자다. 사용자는 “오늘은 어떤 빵이 얼마나 내려갔을까?”를 빠르게 확인하고 구매 시점을 판단하려 한다.

## 5. 핵심 사용자 여정

1. SNS 광고나 공유 링크에서 “매일 오전 9시, 오늘의 빵값이 열립니다”를 보고 접속한다.
2. 빵마켓에서 상품 이미지, 미니 그래프, 정가, 최종가격, 기준가 대비 할인율을 비교한다.
3. 상품을 선택해 최근 7일·14일·1개월 가격 변동을 확인한다.
4. `펼치기`를 눌러 환율 할인과 검색트렌드 할인, 각 기준일을 바텀시트에서 확인한다.
5. `막지몰에서 구매하기`를 누르고 선택 상품과 가격을 재확인한다.
6. 공식 자사몰 `makji.kr`의 해당 상품 페이지로 이동한다.

## 7. 기능 요구사항

### FR-01 빵 시세 목록

- 다섯 상품을 한 행에 하나씩 표시한다.
- 각 행은 실제 상품 이미지, 코드, 상품명, 정가, 미니 가격 그래프, 최종가격, 기준가 대비 할인율을 포함한다.
- 기본 정렬은 `많이 내린 순`이며 `가격 순`, `이름 순`을 제공한다.
- 상품 행 전체를 선택 가능한 터치 영역으로 제공한다.

### FR-02 상품 상세와 가격 그래프

- 상품명, 정가, 오늘 최종가격, 기준가 대비 할인율을 표시한다.
- 7일·14일·1개월 기간을 선택할 수 있다.
- 그래프 축에는 날짜와 가격 범위를 표시한다.
- 최고가, 오늘 가격, 최저가를 그래프 아래에 요약한다.

### FR-03 할인 근거 바텀시트

- `오늘 할인은 어떻게 만들어졌나요?`의 `펼치기`를 누르면 화면 위에 모달 바텀시트가 나타난다.
- 배경은 어둡게 비활성화하며, 닫기 버튼과 바깥 영역 탭으로 닫을 수 있다.
- 환율 할인율, 검색트렌드 할인율, 총 할인율과 각 데이터 기준일을 표시한다.
- 개인의 검색 한 번이 즉시 할인에 반영된다는 오해를 만들지 않는다.

### FR-04 자사몰 이동

- 선택 상품, 최종가격, 공식몰 도메인을 이동 전에 재확인한다.
- CTA는 `막지몰에서 구매 계속하기`로 표시한다.
- 자사몰 내부 주문·결제 화면은 MAKJI STOCK 범위에 포함하지 않는다.

### FR-05 내비게이션

- 하단 메뉴는 `홈·빵마켓·이벤트` 세 개만 제공한다.
- 빵마켓 화면에서는 빵마켓을 활성화한다.
- 홈과 이벤트의 상세 구현은 이번 발표 범위에서 제외한다.

## 8. 가격 정책

```text
환율 하락률 = (직전 영업일 환율 - 최신 확정 환율) / 직전 영업일 환율 × 100
원시 환율 할인 = max(0, 환율 하락률 × 0.28 × 50)
환율 할인 = min(28%p, 원시 환율 할인)
검색트렌드 할인 = 검색지수(0~100) × 0.1
총 할인율 = min(38%p, 환율 할인 + 검색트렌드 할인)
오늘 가격 = 정가 × (1 - 총 할인율 / 100)
```

- 매일 오전 9시에 D-1 검색지수와 최신 확정 USD/KRW 데이터를 반영한다.
- 환율이 상승하거나 같으면 환율 할인은 0%p다.
- 외환시장 비영업일에는 직전 정상 산출값을 이월하고 기준일을 표시한다.
- 할인은 전일 가격이 아니라 정가에 매일 새로 적용한다.
- 총 할인율은 38%p를 초과하지 않는다.

## 9. UX 원칙

- iPhone 17 Pro의 402×874pt를 기준으로 설계한다.
- 본문은 15~17pt, 보조 정보는 최소 12pt, 주요 가격은 32pt 이상을 권장한다.
- 주식시장 문법은 비교와 변화 이해를 돕는 범위에서만 사용한다.
- 실제 금융상품, 투자, 수익을 연상시키는 표현은 피한다.
- 스카이블루, 웜 아이보리, 짙은 네이비를 중심으로 막지의 건강하고 친근한 분위기를 유지한다.

## 10. 성공 지표

- 빵마켓 방문 대비 상품 상세 조회율
- 상품 상세 대비 할인 근거 열람률
- 상품 상세 대비 자사몰 이동률
- 익일 재방문율
- 표시가격과 자사몰 결제가격 일치율
- 데이터 결측·산식 실패·연속 이월 건수

## 11. 출시 조건

1. 다섯 상품의 검색어 묶음과 지수 분포를 검증한다.
2. 자사몰 표시·결제가격 적용 방식을 확정한다.
3. 상품별 원가·마진으로 실제 운영 할인 상한을 검토한다.
4. 기준가격과 할인 표시의 법적 적합성을 검토한다.
5. 모바일 사용성 테스트에서 핵심 과업을 도움 없이 수행할 수 있어야 한다.
