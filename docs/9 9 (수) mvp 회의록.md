## 3. 핵심 로직

### MAKJI 오늘의 빵 시세

### 1. 사용하는 데이터

| 데이터 | API | 역할 | 비용 |
| --- | --- | --- | --- |
| **NAVER 검색트렌드** | NAVER DataLab | 빵별 인기 변화 | 무료 |
| **KOSPI** | 금융위원회 지수시세정보 | 시장 분위기 | 무료 |
| **USD/KRW 환율** | 한국수출입은행 환율정보 | 금융시장 변동 | 무료 |

목적은 실제 원가 계산이 아니라, **외부 데이터에 따라 매일 달라지는 ‘빵 시세’를 만드는 것**입니다.

### 2. 가격 결정 비중

**검색트렌드 60% + KOSPI 25% + 환율 15%**

상품별 검색트렌드가 다르기 때문에 같은 날에도 각 상품 가격이 서로 다르게 움직일 수 있습니다.

### 3. 계산 공식

> **오늘 변동률 = (검색트렌드 변동률 × 60% + KOSPI 변동률 × 25% + 환율 변동률 × 15%) × 5**
> 

계산된 변동률이 너무 크면 아래 **가격대별 상한**을 적용합니다.

### 4. 가격대별 변동 상한

| 기본가격 | 하루 최대 변동 | 예시 |
| --- | --- | --- |
| **1만원 미만** | **±10%** | 3,800원 → 3,420~4,180원 |
| **1만~2만원 미만** | **±7%** | 15,000원 → 13,950~16,050원 |
| **2만원 이상** | **±5%** | 42,000원 → 39,900~44,100원 |

이렇게 하면 저가 상품은 가격 변화가 확실히 보여 재미가 있고, 고가 상품은 하루에 수천 원씩 과도하게 출렁이는 것을 막을 수 있습니다.

### 5. 실제 상품에 적용하면

| 상품 | 기본가격 | 최대 일일 가격 범위 |
| --- | --- | --- |
| 비건 잉글리시 머핀 | 1,500원 | **1,350 ~ 1,650원** |
| 대만식 샌드위치 | 2,400원 | **2,160 ~ 2,640원** |
| 휘낭시에 | 3,800원 | **3,420 ~ 4,180원** |
| 글루텐프리 스콘 | 3,800원 | **3,420 ~ 4,180원** |
| 모닝롤 | 4,500원 | **4,050 ~ 4,950원** |
| 테트리스 브레드 | 11,000원 | **10,230 ~ 11,770원** |
| ZERO 카스테라 | 12,000원 | **11,160 ~ 12,840원** |
| 티라미수 | 15,000원 | **13,950 ~ 16,050원** |
| 냉동생지 3종 | 21,000원 | **19,950 ~ 22,050원** |
| 마틸다 초코케이크 | 42,000원 | **39,900 ~ 44,100원** |

가격은 항상 **전날 가격이 아니라 기본가격을 기준으로 다시 계산**합니다.

> **오늘의 빵 시세 = 기본가격 × (1 + 오늘 변동률)**
> 

예를 들어 휘낭시에가 오늘 +8%라면:

**3,800원 → 4,100원**

다음 날 -6%라면 4,100원을 기준으로 계산하지 않고:

**3,800원 → 3,570원**

으로 다시 계산합니다.

### 최종 구조

**검색트렌드 + KOSPI + 환율**

→ **60 : 25 : 15 가중치**

→ **×5 증폭**

→ **가격대별 ±10% / ±7% / ±5% 제한**

→ **매일 새로운 ‘오늘의 빵 시세’ 생성**

이 정도면 **가격이 바뀌었다는 느낌은 확실히 나면서도, 고가 상품 가격이 지나치게 요동치는 문제는 줄일 수 있습니다.**

→ 예측 성공 시 **할인코드 제공, 임시 할인 URL**

## 4. 기업 연계

**기업이 현재 가진 문제 / 니즈**

→ 온라인몰 재방문을 유도할 콘텐츠 부족

**우리 서비스가 해결하는 부분**

→ 사용자의 자사몰 방문 유도

**기업이 얻는 효과**

→ 상품 노출 증가 → 재방문 증가 → 구매 전환 기회 확대
