## 1. 서비스 소개

> MAKJI STOCK은 **검색트렌드**와 **환율**을 반영해 **매일 새로운 빵 시세와 참여 경험을 제공하는 서비스**입니다.
> 

| 항목 | 작성 내용 |
| --- | --- |
| 서비스명 | MAKJI STOCK |
| 한 줄 설명 | 검색트렌드와 환율 변화를 반영해 매일 달라지는 빵값을 제시하는 데이터 기반 베이커리 마켓 |
| 타깃 사용자 | 매일 달라지는 빵 시세와 혜택을 확인하며, 단순 구매를 넘어 새로운 구매 경험을 즐기는 온라인 베이커리 소비자 |
| 방문 이유 | 매일 달라지는 빵값을 확인하고, 원하는 상품을 저렴하게 구매할 기회를 찾기 위해 |
| 핵심 메시지 초안 | 검색할수록 내려가는 빵값 |

> 매일 바뀌는 가격과 예측 이벤트가 있으면, 사용자는 결과를 보러 다시 오고 구매로 이어질 것이다.

## 2. 기획 배경

**핵심 문장:** 시장 데이터를 활용한 참여 경험으로 MAKJI 자사몰의 재방문과 구매 전환을 유도합니다.

### 2-1. 기업의 RFP

- `[RFP]` 외부 시장 데이터 기반 Bread Market의 실제 동작 MVP 구현·검증
- `[RFP]` 플랫폼 이용 → 상품 관심 → 구매 전환 → 재방문으로 이어지는 구조 설계

### 2-2. 우리가 해결하려는 문제

- 배경: MAKJI의 B2B → B2C 시장 확장 전략의 일환
- 구매할 일이 없어도 자사몰에 재방문할 이유 필요

### 2-3. 서비스 방향

- 고객이 언제, 어떤 이유로 자사몰에 들어오는가?
- 참여 동기: 오늘 가격 확인, 저렴한 구매 기회, 예측 결과에 대한 궁금증.
- 선택한 방향: 가격 탐색과 예측 이벤트를 연결해 다음 날 다시 방문할 이유를 만듭니다.

### 2-4. 프로젝트의 목표

- 사용자 목표: 오늘의 가격과 참여 혜택을 확인하고 상품을 탐색하게 합니다.
- 기업 목표: 재방문과 상품 관심이 구매로 연결되는지 확인합니다.
- 프로젝트 목표: 데이터 수집부터 가격·쿠폰 반영, 행동 측정까지 동작하는 MVP를 만듭니다.

**시각화 예정:** 기업 목표 → 사용자 문제 → 서비스 해결 방향 도식.

## 6. 데이터와 가격 정책

### 6-2. 가격 결정 원칙

- `[팀 제안]` 검색 관심도가 높을수록 가격을 낮추는 방향으로 반영합니다.
- `[팀 제안]` 환율을 합산하므로 최종 가격은 상승하거나 하락할 수 있습니다.
- 매일 기본가격에서 다시 계산하고, 가격대별 한도 적용 후 10원 단위로 반올림합니다.
- 기준점·반영 비율·가격대별 한도는 임시 설정이며, 가격 변화와 원가·마진을 확인한 뒤 조정합니다.
- 현재 검토값: 검색트렌드 ±5%, 환율 전일비 ×3 후 ±3% 제한. 합산 결과는 최대 ±8%입니다.
- `[확인 필요]` 저가 상품의 설정 한도 ±10%와 실제 계산 범위 ±8%를 유지할지, 설정값을 ±8%로 통일할지 결정합니다.
- 기본가격 대비 조정률과 전일 대비 등락률은 다릅니다. 화면에 어떤 값을 표시할지 정합니다.

`[RFP와 팀 제안 구분]` RFP는 일일 할인·이벤트 자동 추천을 예시로 제시합니다. 기본가격보다 높아질 수 있는 판매가 정책은 팀 제안이므로 기업과 적용 범위를 확인합니다.

- `[작성]` 데이터 수집 실패·가격 반영 실패 시 대체 처리와 운영자 확인 방법.
- `[작성]` API 키 관리, 코드 구조, 배포·복구 방법을 인수인계 문서에 정리합니다.
